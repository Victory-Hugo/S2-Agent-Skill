# 何时使用本技能

本技能用于整理已有数据至可用的附表或正文表格，适用于以下场景：
1. 用户提供了原始数据文件（如Excel、CSV、TSV等），需要整理为论文附表或正文表格。
2. 用户提供了分析结果文件（如统计检验结果、模型输出等），需要整理为论文附表或正文表格。
3. 用户需要将多个数据源整合为一个可用的表格，以便在论文中引用。

# 何时不使用本技能

在进行数据分析阶段时不使用本技能。

# 技能使用方法

根据用户提供的数据整理表格至可用的表格，具体要求如下：
1. 输出为`md`格式。默认名为`Table.md`。
2. `md`表格中可以包括多个表格，每个表格都必须要有**表注、解释**。
3. 列名禁止出现内部变量名、日志名、下划线等，必须全部更换为可以理解的自然语言。
