# 质控清单（输出前必检）

使用方式：每次输出图注前，逐项给出“通过/不通过 + 备注”。任何关键项不通过，都必须在“缺失信息与假设声明”中显式提示。

## 检查项

1. 面板覆盖完整性
- 判定标准：所有可见面板均有对应描述；无遗漏、无错位。
- 输出格式：通过/不通过 + 备注。

2. 面板顺序与映射正确性
- 判定标准：A/B/C 顺序与图中标注一致；若无标注，已声明“从左到右、从上到下”推断。
- 输出格式：通过/不通过 + 备注。

3. 统计信息一致性
- 判定标准：统计检验、阈值、显著性符号与输入一致；未提供时未被编造。
- 输出格式：通过/不通过 + 备注。

4. 误差线定义明确
- 判定标准：明确 SD/SEM/CI；若未知则标记“待补充”。
- 输出格式：通过/不通过 + 备注。

5. `n` 的对象定义清晰
- 判定标准：说明 `n` 代表生物学重复、技术重复或样本数；未知则标记待补充。
- 输出格式：通过/不通过 + 备注。

6. 单位与比例尺一致
- 判定标准：单位表达前后一致；显微图包含比例尺信息或明确缺失。
- 输出格式：通过/不通过 + 备注。

7. 缩写首现释义
- 判定标准：中文与英文版本均在首次出现时释义。
- 输出格式：通过/不通过 + 备注。

8. 方法学一致性
- 判定标准：图注中的处理条件、时间点、模型、检测方式与 `methods_context` 一致。
- 输出格式：通过/不通过 + 备注。

9. 中英内容逐项对齐
- 判定标准：中文与英文在面板事实、统计、单位、术语上可一一映射，无语义漂移。
- 输出格式：通过/不通过 + 备注。

10. 结论强度合规
- 判定标准：图注仅陈述图中支持的结果，不扩展为未证实因果结论。
- 输出格式：通过/不通过 + 备注。

## 输出示例

```text
质控清单结果：
1) 面板覆盖完整性：通过 + A/B/C 面板均已描述。
2) 面板顺序与映射正确性：通过 + 使用图中原始标签。
3) 统计信息一致性：不通过 + 未提供检验方法，已在第三部分标注待补充。
4) 误差线定义明确：通过 + 误差线为 SEM。
5) n 的对象定义清晰：不通过 + 仅有 n 数值，无对象定义。
...
```

## 关键红线

1. 不得虚构 `n`、P 值、统计检验、单位、比例尺、处理条件。
2. 不得省略“缺失信息与假设声明”章节。
3. 不得出现中英文事实不一致。
