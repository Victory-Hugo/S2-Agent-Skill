# R 科研绘图示例图库

## 使用

1. 从[示例索引](references/example-catalog.md)选择最接近的图形。
2. 读取所选脚本，检查输入、字段和 R 包。
3. 缺包时列出缺失项，让用户决定是否安装；不要自动安装。
4. 复制并适配示例，不覆盖用户原始数据。
5. 使用系统级 `R` 运行，并检查输出文件和图形。

## 约定

- 保留示例原有颜色和字体，除非用户明确要求修改。
- 脚本按“配置、检查、读取、处理、绘图、输出”排列，使用简短中文注释。
- 输入和输出相对脚本目录定位。
- 不自动下载数据。
- 新增图形时保留 `script/<类别>/<图名>/<图名>.R` 结构，并在索引增加一行。

```bash
Rscript scripts/validate_gallery.R
```
