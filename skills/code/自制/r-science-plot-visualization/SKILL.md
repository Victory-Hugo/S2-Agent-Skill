# R 科研绘图示例图库

## 使用

1. 从[示例索引](references/example-catalog.md)筛选候选图形。
2. 必须完整读取候选 `.R` 脚本及其依赖代码，再确定使用哪个示例。
3. **禁止仅根据图名、截图或经验猜测绘图方法**。
4. 若没有结构一致的示例，应明确说明，不得擅自用其他图形替代。
5. 检查输入字段和 R 包；缺包时只列出缺失项，不自动安装。
6. 复制并适配已读取的示例，不覆盖用户原始数据。
7. 使用系统级 `R` 运行，并检查输出文件和图形是否正确。
8. 回复中列出实际读取的脚本路径。

## 约定

- 保留示例原有颜色和字体，除非用户明确要求修改。
- 脚本按“配置、检查、读取、处理、绘图、输出”排列。
- 输入和输出相对脚本目录定位。
- 不自动下载数据。
- 新增图形时保留 `scripts/<类别>/<图名>/<图名>.R` 结构，并更新索引。

```bash
Rscript scripts/validate_gallery.R
