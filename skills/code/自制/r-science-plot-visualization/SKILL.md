# 何时用此技能
当分析结果需要可视化且符合如下方法时使用此skill。
# 使用要点
首先应当明确分析结果的类型，选择合适的图形进行可视化。优先使用系统级别`R`。
# 图表集合
该 skill 包括以下图形的绘制方法：
1. 表示数据关联及流向：
   * [桑基图](../r-science-plot-visualization/script/1-桑基图/桑基图.R)
   * [分层弦图](../r-science-plot-visualization/script/1-分层弦图/分层弦图.R)
   * [花瓣富集图](../r-science-plot-visualization/script/1-花瓣富集图/花瓣富集图.R)
2. 表示集合交并关系：
   * [韦恩图](../r-science-plot-visualization/script/2-韦恩图/韦恩图.R)
3. 表示数据数量及构成：
   * [统计柱状图与饼图](../r-science-plot-visualization/script/3-柱状图与饼图/统计柱状图饼图.R)
4. 表示相关性：
   * [LinkET图](../r-science-plot-visualization/script/4-LinkET图/linkET.R)
   * [pheatmap配对热图](../r-science-plot-visualization/script/4-pheatmap配对热图/pheatmap配对热图.R)
5. 表示系统发育：
   * [时间树节点气泡图](../r-science-plot-visualization/script/5-时间树节点气泡图/时间树节点气泡图.R)
6. 表示组间差异及统计显著性：
   * [火山图](../r-science-plot-visualization/script/6-火山图/火山图.R)
