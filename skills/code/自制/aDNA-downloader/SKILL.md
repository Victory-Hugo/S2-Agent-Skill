# 古代 DNA 数据收集与下载 Agent

根据用户提供的文献、PDF、补充材料、数据库编号、链接或关键词，收集古代 DNA 样本基础信息和原始测序数据，并按模板输出可追溯结果。

## 核心规则

1. 必须复制 `template/古代DNA收集模板-AI-agent.xlsx` 后再写入，禁止修改原始模板。
2. metadata 输出到 `output/meta/时间戳.xlsx`，数据、下载清单、命令和失败说明输出到 `output/data/`。
3. 除非用户明确说明“仅收集基础信息”或“仅下载原始数据”，否则必须同时收集基础信息并下载或记录原始数据。
4. 若用户主动提供了文章 PDF 和补充材料，基础信息必须优先从用户提供的资料中获取。仅当用户提供资料缺失、无法读取或无法确认字段时，才可查外部数据库、网页或其他来源。
5. 必须保留模板字段、顺序、格式、公式、数据验证、隐藏 sheet、命名区域，以及模板 sheet 第二行原始注释行。
6. 禁止删除、覆盖或清空模板 sheet 第二行原始注释行。
7. 禁止编造信息，禁止留空。缺失或无法确认的信息必须填写模板允许的缺失值、未知值或待复核标记，并记录复核原因。
8. 下拉框字段只能写入模板允许值，禁止写入同义词、缩写、翻译、解释或新类别。
9. 只收集和下载当前研究本身产生的古代 DNA 数据。禁止收集、下载或写入当前研究引用的其他研究、参考数据、比较数据或对照数据。

## 工作流程

### 1. 初始化

创建：

```text
output/
├── meta/
└── data/
```

复制模板生成 `output/meta/时间戳.xlsx`，之后只写入复制文件。

### 2. 读取模板

读取 `模板` sheet 中的字段名、字段顺序、第二行说明、格式、公式、数据验证、下拉框、隐藏 sheet 和命名区域。

禁止用 `pandas.DataFrame.to_excel()` 等方式覆盖模板结构。

### 3. 基础信息收集

若需要收集基础信息，必须先判断用户是否主动提供文章 PDF、补充材料或其他原始资料。

#### 3.1 用户已提供文章 PDF 和补充材料时

必须优先完整检索用户提供的资料，顺序如下：

1. 补充材料中的附表：附表1、附表2、附表3、附表4及后续附表。
2. 文章 PDF 正文中的表格：表1、表2、表3、表4及后续表格。
3. 补充材料正文、方法、说明文字和图表注释。
4. 文章 PDF 正文描述、方法、结果、图表注释和数据可用性声明。
5. 用户提供资料中的 accession、下载链接、样本编号对照表、测序信息表和复核说明。

仅当上述资料无法获取、字段缺失或信息无法确认时，才可继续查外部来源。

#### 3.2 用户未提供文章 PDF 和补充材料时

必须按以下顺序搜索：

1. 优先找附表：附表1、附表2、附表3、附表4及后续附表。
2. 其次找正文表格：表1、表2、表3、表4及后续表格。
3. 若表格中找不到，再查正文描述。
4. 最后查补充材料：补充材料1、补充材料2、补充材料3、补充材料4及后续材料。

#### 3.3 检索记录要求

每类来源都要记录：

* 是否检索。
* 是否命中。
* 提取字段。
* 原始字段名。
* 原文值。
* 标准化值。
* 未命中原因。
* 是否来自用户主动提供资料。
* 是否需要人工复核。

若用户提供资料和外部来源存在冲突，必须优先保留用户提供资料中的信息，并在复核记录中注明冲突来源、冲突字段和处理方式。

### 4. 整理 metadata

将标准化信息写入 `总表` sheet。每条记录必须有可追溯来源，且必须确认属于当前研究本身产生的数据。

每篇文献或数据来源创建一个 `Citation_short` sheet，保存原始表格、数据库记录、下载链接、accession、文件信息、原文描述、复核记录和排除记录。

若基础信息来自用户主动提供的 PDF 或补充材料，必须在 `Citation_short` sheet 中明确记录文件名、页码、表号、附表名、行号、列名或可定位的原文位置。

### 5. 下载或记录原始数据

若需要处理原始数据：

* 优先下载用户指定数据类型。
* 用户未指定时，优先 BAM；无 BAM 时用 FASTQ 或其他可用格式。
* 数据文件保存到 `output/data/`。
* 文件名应能对应 `总表` 中的 `Genetic_ID`。
* 无法下载时，保存 accession、下载命令或失败说明。
* 禁止下载非当前研究产生的数据。
* 若用户提供资料中包含 accession、下载链接或数据可用性声明，必须优先使用这些信息定位当前研究数据。

### 6. 质量检查

完成前必须检查：

* Excel 文件是否存在。
* 是否包含 `总表`。
* 模板 sheet 第二行原始注释行是否保留。
* 字段、格式、公式、数据验证和隐藏内容是否保留。
* 下拉框字段是否均为模板允许值。
* 是否存在空白字段。
* `Genetic_ID` 是否对应数据文件、下载清单或失败说明。
* 是否排除了其他研究、参考数据、比较数据和对照数据。
* 若用户未限定任务范围，是否同时完成基础信息和原始数据处理。
* 若用户主动提供文章 PDF 和补充材料，是否已优先从用户提供资料中提取基础信息。
* 外部来源补充的信息是否均记录了使用原因和复核说明。

最终只列出：

* 已处理文献或数据来源数量。
* 已整理样本或记录数量。
* 已下载、未下载、受限或失败的数据数量。
* 已排除的非当前研究数据数量。
* 需要人工复核的字段或问题。
* 用户提供资料已使用情况。
* 外部来源补充使用情况。

## 禁止行为

* 禁止修改原始模板。
* 禁止破坏模板结构。
* 禁止删除模板 sheet 第二行原始注释行。
* 禁止编造信息。
* 禁止留空。
* 禁止在下拉框字段写入非模板允许值。
* 禁止在用户已提供文章 PDF 和补充材料时，绕过用户提供资料直接以外部来源作为基础信息主来源。
* 禁止收集、下载或写入非当前研究本身产生的古代 DNA 数据。
