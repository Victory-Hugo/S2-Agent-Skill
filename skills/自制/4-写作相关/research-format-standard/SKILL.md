# Research Format Standard

## Scope

凡是科研相关任务，均必须应用本 Skill，包括数据分析、统计分析、论文写作、正文表格、附表、科研插图、补充材料和图注等。

## Mandatory Rules

### 1. Numeric Precision

最终输出的科研文本、表格、附表和科研插图中，凡是出现小数或百分数，均统一保留 **四位有效数字**。

例如：
- 0.123456 → 0.1235
- 12.3456% → 12.35%
- 0.00123456 → 0.001235
- 123.456 → 123.5

统计检验中的精确 *p* 值同样保留四位有效数字。对于极小的 *p* 值，不得四舍五入为 0，应使用阈值形式，例如 *p* < 0.0001。

### 2. Figure Layout

所有正文图和附图中，**每个子图的绘图区必须为正方形**，即 X 轴和 Y 轴的物理长度相等。

该要求针对每个子图独立执行，不要求整张多面板图整体为正方形。

### 3. Significance Notation

凡涉及统计显著性或 *p* 值，**p 必须使用小写斜体**。

正确：
- *p* = 0.01234
- *p* < 0.0001

错误：
- P = 0.01234
- *P* = 0.01234
- p = 0.01234

### 4. Scientific Notation in Word

在 Word 文档中，科学计数法的指数必须使用**普通字符加 Word 上标格式**，禁止直接使用 Unicode 上标字符。

例如，制作 1 × 10 的负四次方时：
1. 输入普通字符 `1 × 10-4`
2. 将 `-4` 设置为 Word 上标格式

禁止直接输入 Unicode 字符形式 `1 × 10⁻⁴`。

该规则适用于论文正文、表格、附表、图注及其他可编辑 Word 内容。

### 5. Operator Spacing

数学运算符和比较符号两侧必须各保留 **一个半角空格**，包括 `×`、`=`、`<`、`>`、`≤`、`≥`、`±` 等。

正确：
- `1 × 10`
- `*p* < 0.001`
- `mean ± SD`
- `*r* = 0.5234`
- `95% CI = 0.1234–0.5678`

错误：
- `1×10`
- `*p*<0.001`
- `mean±SD`
- `*r*=0.5234`

### 6. Italic Statistical Symbols

科研文本、表格、附表、图注和科研插图中，**由拉丁字母表示的统计量、统计参数和数学变量必须使用斜体**。统计检验名称、方法名称以及普通缩写不使用斜体。

常见规范写法包括：
- Mantel *r*
- partial Mantel *r*
- pseudo-*F*
- *F*
- *t*
- *p*
- *r*
- *R*²
- *U*
- *W*
- *H*
- *n*
- *N*
- *df*

例如：
- Mantel *r* = 0.5234, *p* = 0.001234
- partial Mantel *r* = 0.4123, *p* = 0.003456
- PERMANOVA pseudo-*F* = 4.213, *p* < 0.0001
- *t* = 3.421, *p* = 0.002134
- *R*² = 0.5234

统计检验和方法名称保持正体，例如 Mantel test、partial Mantel test、PERMANOVA、ANOVA 和 Student's *t* test。

群体遗传学统计量 *F*ST 中：
- *F* 使用斜体
- ST 使用正体下标

即排版为 *F*<sub>ST</sub>。禁止使用*φ*<sub>ST</sub>。

类似地，*R*² 中仅字母 *R* 使用斜体，数字 2 为正常上标。

希腊字母原则上使用正体，不因其表示统计量或参数而自动设置为斜体，例如 χ²、α 和 β。若目标期刊另有明确格式要求，则遵循目标期刊规范。

## Priority

除非用户明确提出其他要求，否则以上规则均为强制规则。
