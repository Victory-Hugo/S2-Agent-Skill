# 配色规则

## 概述

本文件是从 `color.md` 整理出的权威配色参考。先根据图形语义确定色板类型，再按下述优先级和数量规则选择颜色。

- 分类变量使用 `离散性配色`。
- 单方向连续变量使用 `连续性配色-单色系`。
- 以中点为参照的双向连续变量使用 `连续性配色-双色系`。

## 离散性配色

### 离散性配色-1

- 优先级: 1
- 推荐用途: 分类图、分组比较、离散图例
- Hex 顺序: `#0072b2`, `#56b4e9`, `#009e73`, `#f0e442`, `#e69f00`, `#d55e00`
- 数量规则:
  - 当 `n <= 6` 时，取前 `n` 个颜色
  - 当 `n > 6` 时，先用完这 6 个颜色，再继续使用 `离散性配色-2`

### 离散性配色-2

- 优先级: 2
- 推荐用途: `离散性配色-1` 用尽后的补充颜色
- Hex 顺序: `#8ecae6`, `#219ebc`, `#023047`, `#ffb703`, `#fb8500`
- 数量规则:
  - 仅在 `离散性配色-1` 用完后使用
  - 超过 11 类时的插值锚点集合为:
    `#0072b2`, `#56b4e9`, `#009e73`, `#f0e442`, `#e69f00`, `#d55e00`, `#8ecae6`, `#219ebc`, `#023047`, `#ffb703`, `#fb8500`

### 离散型补充规则

- 当 `7 <= n <= 11` 时，先使用完整的 `离散性配色-1`，再补入 `离散性配色-2` 的前 `n - 6` 个颜色。
- 当 `n > 11` 时，对上面的 11 个锚点色进行均匀插值。
- 当 `n > 11` 时，必须提示颜色区分能力下降，并建议分面、合并类别、形状编码或线型编码。

## 连续性配色-单色系

### 连续性单色-2

- 优先级: 1
- 推荐用途: 热图和有序强度图的默认连续色板
- Hex 顺序: `#0b0405`, `#30203e`, `#3e4d93`, `#366b9f`, `#3488a6`, `#36a4ab`, `#49c1ad`, `#60ceac`, `#84d8b0`, `#c4e9cf`, `#def5e5`
- 数量规则:
  - 连续色标使用完整且有序的色带
  - 分箱时按等距方式抽取 `n` 个颜色

### 连续性单色-4

- 优先级: 2
- 推荐用途: 备用连续单色色板
- Hex 顺序: `#440154`, `#482475`, `#453480`, `#414387`, `#2e6c8e`, `#21908c`, `#42be70`, `#79d150`, `#bbde26`, `#dde318`, `#fde725`
- 数量规则:
  - 连续色标使用完整且有序的色带
  - 分箱时按等距方式抽取 `n` 个颜色

### 连续性单色-3

- 优先级: 3
- 推荐用途: 第二备用连续单色色板
- Hex 顺序: `#0d0887`, `#41039d`, `#7e03a8`, `#a11b9a`, `#be3884`, `#d6556c`, `#e97357`, `#f1834b`, `#f89441`, `#feb92c`, `#fccd25`, `#f0f921`
- 数量规则:
  - 连续色标使用完整且有序的色带
  - 分箱时按等距方式抽取 `n` 个颜色

### 连续性单色-5

- 优先级: 4
- 推荐用途: 在确有需要时使用的蓝白红备用连续色板
- Hex 顺序: `#0000ff`, `#3232ff`, `#6565ff`, `#9898ff`, `#e5e5ff`, `#ffe5e5`, `#ff7f7f`, `#ff6565`, `#ff3232`, `#ff0000`
- 数量规则:
  - 连续色标使用完整且有序的色带
  - 分箱时按等距方式抽取 `n` 个颜色

### 连续单色通用规则

- 所有连续单色色板都必须保持原始顺序。
- 除非用户明确要求反向语义映射，否则不要打乱或反转色带。

## 连续性配色-双色系

### 连续性双色-5

- 优先级: 1
- 推荐用途: 以中点为中心的连续变量默认双色色板
- Hex 顺序: `#5b53a4`, `#456fb1`, `#368cbb`, `#4fa8af`, `#69c3a5`, `#8ad0a4`, `#addda3`, `#c9e99d`, `#e6f598`, `#fefdbc`, `#fef0a6`, `#fdc877`, `#f88f52`, `#e55848`, `#bc2349`, `#a20643`
- 数量规则:
  - 连续双色色标使用完整且有序的色带
  - 对称分箱时按等距方式抽取颜色，并保留平滑的中点过渡
