# 目录结构
- `1-项目状态.md`：**唯一必读**；**每轮重写**。
- `2-任务板.md`：仅进行中+待办，完成即移除。
- `3-重要决定.md`：决策日志，活跃区 + 历史摘要 + 归档指针。
- `docs/`、`archive/`：分步详档与冷归档；**禁止一开始就阅读**；按需求读。
- `AGENTS.md`：工作规范与**维护规范**，改动文档前**必须读**。
- `memory`：写入agent自身的记忆系统，不堆进项目文档。

# 维护
1. **`1-项目状态.md` 每轮重写而非追加**，超过 ~40 行就精简。它是状态不是日志。
2. **任务完成后从 `2-任务板.md` 移除**，不保留已完成清单。
3. **每步结束 squash `3-重要决定.md`**：本步条目压成结论移入 `archive/`，活跃区只留最近 1–2 步 + 历史摘要。
4. **完成的步骤写成独立封存件 `docs/step-0X.md`**，完成后下一轮无需再打开。
5. **memory 分流**：长期、跨会话的偏好与约束进 memory 系统，不进项目文档。
